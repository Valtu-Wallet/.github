# Security policy

Please report vulnerabilities in Valtu, its API, dashboard, SDKs or this organization's repositories to **security@valtu.io**, with the details and how to reproduce them.

- Give us reasonable time to fix the issue before you disclose it.
- Don't access other customers' data or move funds beyond what you need to show the issue.
- Don't run denial-of-service tests against production.

The full policy, and how to verify the code running in Valtu's enclaves, are at <https://valtu.io/docs/security>.
